# 이미지 폴더

이 폴더는 프로젝트의 이미지 파일들을 저장합니다.

## 이미지 파일 규칙

- **파일 형식**: JPG, PNG, GIF 권장
- **파일 크기**: 각 이미지당 1MB 이하 권장
- **파일명**: 영문 소문자, 언더스코어(_) 사용

## 권장 이미지

1. **hardware_connection.jpg** - 하드웨어 연결 이미지
2. **hw504_joystick.jpg** - HW-504 조이스틱 모듈 이미지
3. **usage_example.jpg** - 사용 예제 이미지
4. **test_result.jpg** - 테스트 결과 이미지

## 이미지 추가 방법

1. 이미지 파일을 이 폴더에 저장
2. README.md에서 주석을 해제하고 파일명 수정
3. Git에 커밋 및 푸시
